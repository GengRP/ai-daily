### [Anthropic 用 Claude 把自家 API 从 Python 改写成 Rust：CPU 省 70%，内存省 80%](https://www.anthropic.com/research/migrating-api-to-rust)

Anthropic 公开了迁移复盘，让 Claude agent 在真实流量旁边「影子运行」新版本、对照结果，每次请求 CPU 少用约 70%，内存少 80% 多，首个字出来的时间中位数快了约 20%。

> [!tip]
> 大改造也能让 AI 干，关键是让新旧版本并排跑、对得上再切换

### [Google Workspace 的 MCP 正式上线，AI agent 2027 年 2 月起必须改用 MCP](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html)

Gmail、Drive、Docs、Sheets、日历等都能通过 MCP 接给 AI，免费档覆盖 99% 以上的开发者。Google 定了期限：2027/2/1 起 AI agent 访问 Workspace 不能再走老的 REST 接口。

> [!tip]
> MCP 正在变成「AI 接软件」的标准插口，普通人以后让 AI 帮忙处理邮件和文档会越来越顺

### [有人用 Claude Opus 5.5 写了一部 25 分钟的交响曲，烧掉约 350 亿 token](https://danprice.ai/blog/opus-symphony)

Dan Price 让一个 Claude 当作曲，几个 Claude 分别当旋律、和声、配器、好不好演奏的「评委」，来回改了约 2,400 轮；乐谱用文本格式写，Claude 能像改代码一样改。

> [!tip]
> 没法判断对错的创作，可以靠「多个评委反复挑刺」来提高质量，写文章、做设计也能借这招

### [美国俄亥俄州律师引用 AI 编造的判例，被无限期停业](https://thelegalwire.ai/ohio-supreme-court-indefinitely-suspends-attorney-over-fabricated-ai-generated-case-citations/)

她在 2025 年的诉状里引用了 4 个不存在的案例，法官问起来还否认，后来才承认是用 AI 写的；联邦法院已罚 7,500 美元。

> [!tip]
> AI 给的引用和出处一定要自己点开看，这是用 AI 的第一条安全常识
