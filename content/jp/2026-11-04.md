### [Postman を開くと Claude Code と Codex の設定が勝手に書き換わる](https://github.com/postmanlabs/postman-app-support/issues/14370)

GitHub への報告によると、Postman デスクトップ版 12.33.4 は起動するだけで Claude Code と Codex にプラグインを入れ、設定ファイルを書き換え、API 関連の作業を自社の skill に回す起動フックを追加し、その信頼設定まで自分で承認していた。Hacker News で2位。

### [Shopify：AI 経由の流入が2.6倍、Meta の Muse がそのまま購入まで](https://www.cnbc.com/2026/11/03/shopify-q3-2026-earnings-gmv.html)

Shopify の第3四半期売上は37.4億ドルで32%増。AI 経由の注文は3.3倍で、7割以上が売れ筋以外のカテゴリー。Meta の消費者向け AI アシスタント Muse が Shopify の店を見て回り、Shop Pay で支払いまでできるようになった。

> [!tip]
> これからは AI が代わりに買い物をする。小さなお店の商品ページは AI に読まれる前提で書く

### [Siri の AI 機能がすべてのアプリに開放、日本語にも対応](https://developer.apple.com/news/?id=gdk2umrf)

iOS 27.3 などのベータで開発者プレビューが始まり、どのアプリも App Intents で内容や操作を Siri につなげられる。画面の理解や複数ステップの操作も含む。最初の言語は英・仏・日・韓・葡・西で、App Store への提出は来年春から。

> [!tip]
> 「Siri に一言でアプリの用事が終わる」を日本のユーザーが先に使える

### [Anthropic が FlashProve を公開：回答をどのモデルが書いたか証明できる](https://www.anthropic.com/research/provable-inference)

EPFL・MIT との共同研究。ゼロ知識証明で、重みを公開せずに回答が特定の重みから出たことを確認する。代わりに計算量はモデルを動かすだけの70〜95倍。

> [!tip]
> 使っている API は本当にお金を払ったモデルなのか

### [米決済大手 Fiserv、「どこでも AI」を掲げて3000人を削減](https://www.pymnts.com/earnings/2026/fiserv-wants-ai-to-fix-what-decades-of-payments-growth-made-expensive/)

従業員の約8%で、幹部も1割以上減らした。コスト削減目標を10億ドルに倍増し、不正審査・顧客対応・コード作成を AI で自動化する。発表後、株価は約9.5%上昇。

> 「AI でリストラ」の発表が増える中、置き換えられているのはどんな仕事か
