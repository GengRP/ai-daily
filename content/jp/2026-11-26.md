### [Anthropic が Claude を使って自社 API を Python から Rust に書き直し：CPU 70%減、メモリ80%減](https://www.anthropic.com/research/migrating-api-to-rust)

Anthropic が移行の振り返りを公開。Claude のエージェントに新バージョンを本番トラフィックの横で「シャドー運転」させて結果を照合し、1リクエストあたり CPU 約70%減、メモリ80%以上減、最初の文字が出るまでの時間の中央値が約20%速くなった。

### [Google Workspace の MCP が正式公開、AI エージェントは2027年2月から MCP 必須に](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html)

Gmail、Drive、Docs、Sheets、カレンダーなどを MCP で AI につなげる。無料枠で開発者の99%以上をカバー。Google は期限も決めた：2027/2/1 以降、AI エージェントは従来の REST API で Workspace にアクセスできなくなる。

> [!tip]
> MCP は「AI とソフトをつなぐ標準の差し込み口」になりつつある。メールや書類の処理を AI に頼むのがどんどん楽になる
