### [Report: Claude Code sends the user's email with web requests](https://github.com/anthropics/claude-code/issues/107757)

A developer on GitHub says Claude Code puts the signed-in user's email address in the User-Agent of its web requests, so every site it visits can see it. He blames it for dozens of scam emails a day and wants Anthropic to remove it outright. It reached the Hacker News front page.
