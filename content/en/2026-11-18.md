### [Codex finds a critical Java bug in 20 minutes, and Oracle patches it the same day](https://calif.io/java4shell/)

A researcher at security firm Calif used OpenAI's Codex, with about 20 minutes of prompting and under $200 in tokens, to find a pre-auth remote code execution bug in OpenJDK 17, 21 and 25 (dubbed Java4Shell, severity 9.2). Oracle shipped a fix that day.

> [!tip]
> AI finds bugs fast and cheap, for attackers and defenders alike. Keep Java on your machine updated

### [California bans Waymo robotaxis from freeways](https://wtop.com/national/2026/11/california-bans-waymo-autonomous-vehicles-from-state-freeways-saying-they-pose-an-imminent-hazard)
