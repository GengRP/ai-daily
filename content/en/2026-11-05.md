### [Top models drop to 13% when tracking changing values in long documents](https://allenai.org/blog/statebench)

The Allen Institute for AI (Ai2) released StateBench, which tests whether models can keep track of variables that change across a long document. Gemini, Claude Opus 5.5 and GPT-6 did well on easy versions but all fell to 13% or lower on the hardest level.

> [!tip]
> when AI reads a long contract or spreadsheet, which parts you should still check yourself

### [Claude finds two critical flaws in the Xen hypervisor](https://thehackernews.com/2026/11/xen-hypervisor-flaws-let-one-malicious.html)

Xen's official advisory credits Claude. The flaws let one malicious virtual machine read and write the memory of other VMs on the same host, affecting every release from 4.6 on; third parties have reproduced them.
